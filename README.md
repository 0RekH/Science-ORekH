# Science-ORekH
Этот репозитория посвящен научной, профильной деятельности в МГУ им. М. Ю. Ломоносова, а именно изучению зон накопления частиц в многофазных потоках(смесь газа и пыли разных частиц). Работа проводится на кафедре аэромеханики и газовой динамики под руководством А. Н. Осипцова.
